# java-racingcar-precourse

### 기능 요구 사항
1. 주어진 횟수 동안 n대의 자동차는 전진 또는 정지
2. 각 자동차에 이름 부여 가능, 전진하는 자동차를 출력할 때 자동차 이름 같이 출력
3. 자동차 이름은 쉼표(,)를 기준으로 구분하며 이름은 5자 이하만 가능
4. 사용자를 통해 몇 번의 이동을 할 것인지 입력
5. 전진하는 조건은 0에서 9 사이에서 무작위 값을 구한 후 무작위 값이 4 이상일 경우
6. 자동차 경주 게임을 완료한 후 누가 우승했는지 출력, 한 명 이상의 우승자 가능
7. 우승자가 여러명일 경우 쉼표(,)를 이용하여 구분
8. 사용자가 잘못된 값을 입력할 경우 IllegalArgumentException을 발생시킨 후 애플리케이션 종료

### 입출력 요구 사항

##### 입력
- 경주할 자동차 이름(이름은 쉼표(,) 기준으로 구분)
```
pobi,woni,jun
```
- 시도할 횟수
```
5
```

##### 출력
- 차수별 실행 결과
```
pobi : --
woni : ----
jun : ---
```
- 단독 우승자 안내 문구
```
최종 우승자 : pobi
```
- 공동 우승자 안내 문구
```
최종 우승자 : pobi, jun
```

##### 실행 결과 예시
```
덧셈할 문자열을 입력해 주세요.
1,2:3
결과 : 6
```

### 구현 기능 목록
- [x] 쉼표(,)를 기준으로 구분한 자동차 이름 및 시도할 횟수 입력
- [x] **자동차 이름** 유효성 검증: 이름이 5자 이하인지 확인, 초과한 경우 IllegalArgumentException 발생
- [x] **시도할 횟수** 유효성 검증: 횟수가 양의 정수인지 확인, 잘못된 값을 입력한 경우 IllegalArgumentException 발생
- [x] 0과 9사이에서 무작위 값을 생성한 후 무작위 값이 4 이상일 경우 해당 자동차를 전진
- [x] 주어진 횟수 동안 모든 자동차는 전진 또는 정지 반복 실행
- [x] 각 자동차의 전진 횟수를 하이픈(-)으로 표현하여 출력
- [x] 가장 멀리 전진한 자동차를 기준으로 우승자 결정
- [x] 우승자가 한 명일 경우 단독으로 출력, 우승자가 여러 명일 경우 쉼표(,)로 구분하여 출력
